# Security policy

Security reports for this plugin should be sent privately. Use [GitHub's private vulnerability reporting](https://github.com/digicyfr/digicyfr-opening-hours-pl/security/advisories/new) if the repository offers it. Otherwise, contact Digicyfr through [digicyfr.com](https://digicyfr.com/) and request a private security channel. Do not put exploit details, credentials, or real business data in a public issue.

Include the affected plugin version, WordPress/PHP versions, reproduction steps using synthetic data, and the impact. Maintainers will investigate and coordinate a fix and disclosure. No response deadline or bounty is promised.

The supported release is the latest versioned ZIP published on this repository and Digicyfr's plugin page. Older versions are not guaranteed security updates.
