## English

**Title:** Opening Hours PL — free WordPress plugin

**Summary:** Show one location's weekly opening hours for the next seven dates, with manually entered exceptions and a temporary notice. Add a WordPress block or `[digicyfr_opening_hours]` shortcode.

**Setup:** Upload and activate the ZIP under Plugins → Add New → Upload Plugin. Open Settings → Opening Hours PL, enter up to four time intervals per day, add dated closures or changed hours, then insert the block or shortcode on a page. Times use the site's WordPress timezone; choose a city timezone if daylight-saving changes matter.

**Limits:** The schedule is entered manually. The plugin does not calculate Polish holidays, trading Sundays, or whether a location is open now. A cached page needs a short cache lifetime or a purge at local midnight to show the correct next seven dates. It makes no legal claims and sends no data to Digicyfr.

**Compatibility tested:** WordPress 7.1 and PHP 8.3.33, including interactive block insertion. Older/newer versions and multisite network behavior were not verified. A manual screen-reader check remains open. Updates are manual ZIP installs in 0.1.0.

## Polski

**Tytuł:** Opening Hours PL — bezpłatna wtyczka WordPress

**Opis:** Pokaż godziny otwarcia jednej lokalizacji na najbliższe siedem dni, z ręcznie wpisanymi wyjątkami i czasowym komunikatem. Wstaw blok WordPress albo shortcode `[digicyfr_opening_hours]`.

**Konfiguracja:** Prześlij i aktywuj plik ZIP przez Wtyczki → Dodaj nową → Wyślij wtyczkę. Otwórz Ustawienia → Opening Hours PL, wpisz do czterech przedziałów godzin dziennie, dodaj daty zamknięcia lub zmienione godziny, a następnie wstaw blok albo shortcode na stronie. Wtyczka używa strefy czasowej witryny; wybierz strefę miasta, jeśli istotne są zmiany czasu letniego.

**Ograniczenia:** Grafik wymaga ręcznego wprowadzania. Wtyczka nie wyznacza polskich świąt, niedziel handlowych ani bieżącego statusu „otwarte”. Strona z pamięcią podręczną potrzebuje krótkiego czasu przechowywania lub odświeżenia o lokalnej północy, aby pokazywać właściwe siedem dni. Wtyczka nie potwierdza zgodności z prawem i nie wysyła danych do Digicyfr.

**Sprawdzona zgodność:** WordPress 7.1 i PHP 8.3.33, w tym interaktywne wstawianie bloku. Nie zweryfikowano starszych ani nowszych wersji i sieci multisite. Test z czytnikiem ekranu pozostaje do wykonania. W wersji 0.1.0 aktualizacje wykonuje się ręcznie przez ZIP.
